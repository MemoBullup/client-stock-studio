# Client Stock Studio

Chat el día de hoy trabajaremos en un nuevo proyecto de un cliente para poder capturar su inventario, te dejo un prompt previo adjunto junto con el diseño de interfaz deseado, para que te sirva de inspiración. Adicional el logo del cliente para que lo agregues en lugares estratégicos. Gracias.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://client-stock-studio.lovable.app

